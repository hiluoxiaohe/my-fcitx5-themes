自制的输入法皮肤，适用于fcitx5输入法框架，洛天依以及明日方舟维什戴尔主题
使用方法：
1.下载主题文件夹并解压
2.复制到~/.local/share/fcitx5/themes/
3.重启fcitx5
4.打开fcitx5配置界面，选择对应主题并应用
